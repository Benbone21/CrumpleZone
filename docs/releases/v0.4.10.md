# Crumple Zone v0.4.10

- **Automatic updates:** the game now checks for a new release when it starts and offers UPDATE NOW or LATER. It downloads the update, checks its signature, installs it and restarts, and goes back to the old version if the new one won't start. Windows, Mac and the Linux per-user install update themselves. A .deb install tells you where to get the new .deb.
- **Mac builds are back:** the first since 0.4.7.
- **Smoother procedural world:** no more hitch on the frame where the world slides along with you.

Install this release by hand; later ones arrive on their own. In multiplayer it plays with 0.4.8 and 0.4.9.
