Performance, multiplayer, towing and drivetrain improvements.

## Downloads

- Windows 10/11, 64-bit: `CrumpleZone-0.1.6-windows-setup.exe`. Run the installer, then open Crumple Zone from the desktop or Start menu.
- Linux: `CrumpleZone-0.1.6-linux.deb`.
- macOS: `CrumpleZone-0.1.6-mac.zip`.

## Changes

- Faster physics with many vehicles: persistent workers, swept collision bounds and cached collision geometry. Settings now let you choose AUTO or any thread count up to all available logical CPUs. AUTO uses up to four threads; choosing ALL permits the whole CPU.
- Windows graphics improvements: avoid duplicate multisampling, validate HDR targets and fall back to supported sample counts. F3 shows the active GPU and CPU timings; graphics diagnostics are saved in `%APPDATA%\crumplezone\graphics.log`.
- Multiplayer improvements: smoother vehicle playback, shared nearby engine sounds, synchronized headlight switches and correct late-join state. **Both players must update; this build uses multiplayer protocol 3.**
- Mouse/controller recovery-point selection: V opens the winch picker; O (letter O) chooses your tow-strap point, then the other vehicle's. Unattended towed vehicles release their brakes and temporarily select neutral.
- Adjustable winch speed, saved in Settings; default 4x. Use -/= or the WINCH SPEED setting. Rated pull and line strength remain physical limits.
- Manual gears now include neutral (R-N-1...). Fixed reverse throttle-release assistance, added engagement/downshift guards, and improved clutch/RPM matching during driver-selected shifts.
- Revised procedural engine voices and prepared engine-specific recorded-loop playback for local and multiplayer cars. **Actual car recordings are not included yet; this release still uses procedural audio.**

## Validation and limits

Linux game and Windows game/test executables build. All 27 audio checks, offscreen render integration and the final 26 affected physics scenarios pass. The full physics suite has 19 known pre-existing failures after the affected recheck; seven network scenarios cannot open sockets in the development sandbox. Native Windows/NVIDIA hardware and live two-PC play still need testing. Release CI includes native Windows networking, audio and deterministic worker checks.
