Crumple Zone now runs on Mac. Every release has a build for each platform.

## Downloads
| File | Platform | How to run |
|---|---|---|
| `CrumpleZone-0.1.1-mac.zip` | macOS 11+, Apple silicon and Intel | Unzip and open **CrumpleZone.app**. It isn't notarized, so the first time, right-click it and choose **Open**. |
| `CrumpleZone-0.1.1-windows.zip` | Windows 10/11, 64-bit | Unzip and run `crumplezone.exe`. Keep `SDL2.dll` and `assets` beside it. |
| `CrumpleZone-0.1.1-linux.deb` | Debian 13+ / Ubuntu 24.04+, amd64 | `sudo apt install ./CrumpleZone-0.1.1-linux.deb`, then run `crumplezone`. |

## What's new
- **macOS build:** one universal app for Apple silicon and Intel Macs, with SDL2 bundled.
- **Clearer download names:** each file says mac, windows or linux.
- **Every platform built on every change:** the game is now built for all three on each push, so a break on one platform shows up straight away.

## Known issues
- The Mac build has only been compiled and started on GitHub's macOS servers, which have no screen. It hasn't been played on a real Mac yet. Please report anything odd.
- Everything listed for 0.1.0 still applies:
  - no scanned props yet
  - the UTV is slow in the whoops and its governor overshoots slightly
  - the buggy lands a few cm deep on 2 m drops
  - the 4Runner's frame tail can bend coming off a tall ledge
