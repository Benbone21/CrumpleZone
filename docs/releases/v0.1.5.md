A new multiplayer screen, games on your network found more reliably, and a main menu of its own.

## Downloads
| File | Platform | How to run |
|---|---|---|
| `CrumpleZone-0.1.5-windows-setup.exe` | Windows 10/11, 64-bit | Run it to install (no admin needed). If Windows warns about an unknown publisher: More info > Run anyway. |
| `CrumpleZone-0.1.5-linux.deb` | Debian 13+ / Ubuntu 24.04+ | `sudo apt install ./CrumpleZone-0.1.5-linux.deb`, then run `crumplezone`. |
| `CrumpleZone-0.1.5-mac.zip` | macOS 11+ | Unzip, right-click CrumpleZone.app > Open (it isn't notarized). |

## What's new
- **Multiplayer has two clear halves.** HOST A GAME: name your game, pick the map and how many players (2-8), start hosting. JOIN A GAME: games on your network show up by themselves with their name, host, map and player count; pick one. Typing an address still works for games on other networks.
- **Games on your network are found more reliably.** The game now asks on every network adapter (wired and Wi-Fi, VPNs), and hosts also announce themselves, so it works if either direction gets through a firewall. Each game is listed once.
- **Joining doesn't freeze the game.** A card shows while it connects (Esc cancels) and says why if it can't.
- **The main menu is its own screen**, with nothing behind it.
- **Windows Firewall:** the first time you host or look for games, allow Crumple Zone on **Private networks**. The game uses ports 27015 (game), 27016 and 27017 (finding games).
- Version 0.1.4 can still find and join 0.1.5 games and the other way around, but play on the same version: the physics changed.
