Better frame rates on laptops with two graphics chips.

## Downloads
| File | Platform | How to run |
|---|---|---|
| `CrumpleZone-0.1.3-windows-setup.exe` | Windows 10/11, 64-bit | Run it to install (no admin needed). If Windows warns about an unknown publisher: More info > Run anyway. |
| `CrumpleZone-0.1.3-linux.deb` | Debian 13+ / Ubuntu 24.04+ | `sudo apt install ./CrumpleZone-0.1.3-linux.deb`, then run `crumplezone`. |
| `CrumpleZone-0.1.3-mac.zip` | macOS 11+ | Unzip, right-click CrumpleZone.app > Open (it isn't notarized). |

## What's new
- **Uses your graphics card.** On laptops with both a built-in chip and an NVIDIA or AMD graphics card, the game now asks for the fast card. Before, Windows ran it on the much slower built-in chip.
- **See which chip is drawing.** F3 now shows the graphics chip's name under the FPS. If it still shows the built-in chip (for example "AMD Radeon(TM) Graphics" instead of your NVIDIA card), go to Windows Settings > System > Display > Graphics, add crumplezone.exe, and set it to **High performance**.
- **Faster on Windows.** The Windows build is compiled for any x86-64 CPU from about 2009 on, not the oldest ones.
