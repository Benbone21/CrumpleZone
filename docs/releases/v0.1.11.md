# Crumple Zone 0.1.11

This release reduces world rendering work with terrain LOD and spatial culling.

## Downloads

- Windows: `CrumpleZone-0.1.11-windows-setup.exe`.
- Mac: `CrumpleZone-0.1.11-mac.dmg` or `CrumpleZone-0.1.11-mac.zip`, containing a universal Apple Silicon/Intel app. The app is ad-hoc signed, not notarized.
- Linux: `CrumpleZone-0.1.11-linux.deb` for amd64.
- Verify packaged downloads with `SHA256SUMS`.

## Changes

- Split terrain into camera-culled chunks with four distance detail levels. Nearby terrain retains its original detail; matching chunk boundary vertices prevent gaps between different LODs.
- Cull the mountain backdrop and spatially batch static boxes, trees, rocks, bushes and fixtures. Camera and shadow passes use their own frustums, preserving offscreen shadow casters.
- Keep terrain and object edits synchronized with culling bounds and render batches. Terrain height edits update the vertex buffer shared by every LOD.
- Add geometry counts to scripted benchmark output and geometry regression checks to the Linux, Windows and macOS release jobs.

## Verification and performance

The Backcountry capture submits 177,516 terrain triangles instead of 3,055,000, including the backdrop: about 94% fewer. A proving-ground integration view submits about 89% fewer terrain triangles.

Two short, interleaved Linux llvmpipe software-rendering comparisons at 480x270 LOW, with adaptive quality disabled, measured original scene times of 260.38/261.48 ms and new times of 114.04/113.14 ms. This is approximately 56% less scene time on that software renderer. Render resolution and requested graphics settings were identical; distant terrain geometry is simplified by LOD. These results do not establish native Mac or Windows GPU FPS gains.

Local geometry and offscreen rendering checks pass, including all four graphics presets, different LOD boundaries, behind-camera rejection, terrain raised into view by editing, object rebuilds, MSAA fallback and resizing. The Linux game builds, and the changed Windows renderer/main files and geometry test cross-compile. Native platform regression checks and packaging checks gate publication through the release workflow.

The full physics suite was not rerun for this rendering change. The thirteen previously documented physics failures remain known. Distance LOD transitions can cause distant terrain to change shape; grass, water, vehicles and fragment-shader costs are unchanged. See the [implementation and measurements](https://github.com/Benbone21/CrumpleZone/blob/v0.1.11/docs/culling-lod.md).
