# Crumple Zone 0.1.7

## Compatibility and graphics

- VSync follows the saved setting on NVIDIA, AMD, Intel and Apple GPUs. GPU names are logged for diagnostics and no longer silently override VSync.
- Ground and prop textures check optional anisotropic-filtering support before using it; ordinary mipmap filtering remains available on OpenGL 3.3 drivers without the extension.
- macOS networking handles the absence of `MSG_NOSIGNAL` and protects sockets against disconnect signals.
- Release checks now include native macOS networking, audio, rendering and deterministic serial/parallel simulation. The packaged Mac app must render a screenshot and load its ground assets from outside the source folder before publishing.

## Trail repairs and vehicle durability

This release also includes the previously committed field-repair update: repair supplies, jack interactions, faster wheel work and pressure-based tire visuals. The Bronco, 4Runner, Tacoma and side-by-side retain increased frame durability. Truck body strength keeps the previous crash deformation behavior; the proposed threefold increase caused crash regressions and was removed during verification.

## Verification

See [the platform verification report](https://github.com/Benbone21/CrumpleZone/blob/v0.1.7/docs/platform-verification.md) for local build/test results and known failures. Linux rendering and audio checks pass; the Windows game and CPU test tools cross-compile. **441/461 scenario checks pass**; the 20 remaining failures reproduce with the previous vehicle settings (13 existing physics failures and seven sandbox-denied networking tests). All five regressions introduced by the proposed body-strength increase are corrected. Native macOS and Windows execution and hardware performance remain subject to the release workflow and hardware testing. The renderer remains OpenGL; this release does not include a Metal backend or measured Mac/NVIDIA FPS gains.
