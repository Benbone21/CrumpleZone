Multiplayer fixes, and games on your network show up by themselves.

## Downloads
| File | Platform | How to run |
|---|---|---|
| `CrumpleZone-0.1.4-windows-setup.exe` | Windows 10/11, 64-bit | Run it to install (no admin needed). If Windows warns about an unknown publisher: More info > Run anyway. |
| `CrumpleZone-0.1.4-linux.deb` | Debian 13+ / Ubuntu 24.04+ | `sudo apt install ./CrumpleZone-0.1.4-linux.deb`, then run `crumplezone`. |
| `CrumpleZone-0.1.4-mac.zip` | macOS 11+ | Unzip, right-click CrumpleZone.app > Open (it isn't notarized). |

## What's new
- **The host now sees the player who joined.** If a computer had hosted a game before (or joined one), its truck kept that session's network ID. The host then took that truck to be its own and never showed it. Every session now gives vehicles fresh IDs.
- **No more trucks spawning inside each other.** The joining player starts in the first clear spot beside the spawn, away from the host's trucks and the other players. Levels without a start line now place each player side by side.
- **Games on your network are found automatically.** Open Menu > Multiplayer and games hosted on your network are listed as JOIN rows; pick one. Typing an address still works.
- **Windows Firewall:** the first time you host, Windows asks whether to allow Crumple Zone. Tick **Private networks** and allow it, or others can't find or join your game. The game uses ports 27015 (game) and 27016 (finding games).
