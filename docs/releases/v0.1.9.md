# Crumple Zone 0.1.9

This release brings the field-repair, compatibility, soundscape, autopilot and vehicle-tool work together on `main`.

## Downloads

- **Windows:** `CrumpleZone-0.1.9-windows-setup.exe` installs the game, SDL2 and assets with Start menu/desktop shortcuts.
- **Mac:** `CrumpleZone-0.1.9-mac.dmg` contains the universal Intel/Apple Silicon app. Open the disk image and drag the app to Applications. The app is ad-hoc signed and not notarized; first launch may require right-click → Open. A ZIP is also provided.
- **Linux:** `CrumpleZone-0.1.9-linux.deb` is the amd64 Debian/Ubuntu package.

## Changes

- Merge all outstanding feature branches and preserve their history, including the previously uncommitted autopilot and vehicle-tool prototypes.
- Add wind, foliage, birds and night insects, a saved ambience volume, Backcountry music, master mute fixes and smoother engine/cabin/distance transitions.
- Add a CC0 PCM audio-bank importer. Real vehicle recordings are not bundled; missing recordings retain procedural engine voices.
- Preserve the high-speed damping and free-coil suspension experiments as opt-in developer tests while retaining verified suspension defaults, with field-repair supplies, jack interactions, faster wheel work and tire-pressure visuals.
- Use the map's spatial lookup to gather nearby autopilot obstacles in deterministic order. Preserve optional profiling without data races between test threads.
- Merge vehicle names, command-popup logic and removal helpers. Removing a followed car stops its followers; remaining references follow the correct indices. The new command popup's rendering/input integration remains planned.
- Give Windows scratch caches native thread-exit cleanup, avoiding a MinGW runtime crash exposed by native CI. Add repeated cleanup and networking/autopilot stress checks.
- Retain the VSync, optional texture-filtering and macOS socket compatibility fixes from the earlier review.
- Build and verify the Mac DMG, its signed universal app and Applications shortcut in release CI. Publish only after the Linux, native Windows and Mac checks succeed.

## Verification

The initial full regression run passes **448/468 scenarios**, with the same failure set as the previous verified build. After restoring socket access, **all ten networking scenarios pass**, leaving thirteen known physics failures. All seven newly merged functional checks, 41 audio checks and five importer tests pass. Linux GPU and software-renderer checks pass. Publication requires native Windows thread-exit stress, audio, networking and deterministic simulation checks, plus native Mac regression checks and a successful packaged-app render. Hosted Mac graphics use Apple Software Renderer; they establish compatibility, not real Mac GPU performance. Checks and remaining limitations are recorded in the [merge verification report](https://github.com/Benbone21/CrumpleZone/blob/v0.1.9/docs/release-merge-0.1.9.md). The standalone autopilot benchmarks retain the planned 2 ms target, which is not yet met; this release does not claim the planned sensing overhaul or measured Mac/NVIDIA FPS gains.
